Your provider quota

Groq reports organisation-level daily request limits and per-minute token limits. Each model below shows the last quota snapshot returned by the provider, including used, remaining and reset time. These limits may be shared with your other apps and must not be added together across models.

Snapshots update when Acquenta calls that model. They are not live balance checks. Expired snapshots are labelled; refreshing this page only reloads recorded data.

Tracking coverage

Calls are actual model invocations from this app, including retries, background embedding batches and failures. Tokens are reported only where returned by the provider. Costs, billed audio units and Cloudflare account-wide remaining neuron balance are not returned by the current integrations. Estimated app neuron usage is calculated from reported tokens and published model rates, separate from the account balance.

This meter stores no user identities, prompts, generated text or recordings. Device OCR and device speech have no central API call counter.
